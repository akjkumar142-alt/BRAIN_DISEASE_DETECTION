🧠 Brain Disease Detection System (ResNet-50)

An AI-powered Brain Disease Detection system built using Deep Learning in Python. This project uses the ResNet-50 model to analyze MRI images and classify them into major brain diseases such as Tumor, Stroke, and Alzheimer’s. It also includes a chatbot assistant and hospital information module to support users.

🚀 Features
🔍 Disease Classification
Brain Tumor
Stroke
Alzheimer’s Disease
Implemented using ResNet-50 (Transfer Learning)
🤖 Chatbot Support
Assists users with basic medical queries
Provides guidance and recommendations
🏥 Hospital Information
Displays details of well-known hospitals
Helps users access medical care quickly
⚡ Fast & Accurate Predictions
Efficient image preprocessing
Reliable deep learning model

🧪 How It Works
MRI image is provided as input
Image is preprocessed using OpenCV
ResNet-50 model performs classification
Output shows predicted disease
Chatbot assists user with additional info
Hospital module suggests medical facilities
🎯 Objective

To enable early detection of brain diseases using AI and provide supportive healthcare information through chatbot and hospital details.
